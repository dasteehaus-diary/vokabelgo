⚠️ Chưa phát hiện cấu hình Supabase: Hãy dán Project URL và anon public key từ Supabase Dashboard vào ô dưới để kích hoạt tài khoản đám mây!
📌 Cách lấy thông tin trong 30 giây:
1. Vào supabase.com → Chọn Project của bạn.
2. Bấm icon bánh răng ⚙ Project Settings ở thanh menu góc trái dưới → Chọn API.
3. Copy Project URL và anon public key dán vào 2 ô trên!
4. (Mẹo): Trong Supabase, chọn SQL Editor → chạy nội dung tệp supabase_schema.sql để tạo bảng tự động.
